## 파일럿 중 실전 검출 (도구 가치의 실증)

홈 화면 스모크가 콘솔 에러 32건으로 **옳게 실패**:
```
line 1:5 mismatched input 'instanceCode' expecting ENTITY_TYPE
```
= **BANK 커스텀(기준코드) 데이터가 공식 1.13.2 위에 마이그레이션돼 있는데 커스텀 코드는 아직 재적용 전**이라 서버 파서가 엔티티 타입을 모르는 상태. **om-verify가 잡도록 만드는 바로 그 부류의 업그레이드 호환성 결함**을 후보 도구가 파일럿 중 검출. (랩 상태로는 예상된 것 — upgrade apply가 아직 STOP 상태이므로. 이 증상은 upgrade 재적용 후 사라져야 정상이며, om-verify의 회귀 지표로 쓸 수 있음.)
