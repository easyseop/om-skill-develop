# /om-plan — 개요와 경위

## 무엇을 만드는가

OpenMetadata 커스터마이징 작업(최초 등록·신규 기능·기존 수정·버전업)을
`/om-plan <모드>` 한 명령으로 시작하게 하는 **계획 전용** 슬래시 명령.
LLM은 조사·제안만 하고, 코드 수정은 다음 단계(/om-implement 후보)에서 사람 승인 후에만 한다.

역할 3분할이 설계의 뼈대다:
- **LLM** — 의미 해석·계획 제안 (제안은 전부 `proposed` 라벨)
- **검사기(Python·Schema)** — Git 사실 수집·형식 검증·digest 결속 (LLM은 `observed`를 만들 수 없음)
- **사람** — 업무 의미·위험·승인 판단 (STOP 지점에서만)
