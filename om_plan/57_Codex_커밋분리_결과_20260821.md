## 3. hunk 분리 방법

- `collectors.py`는 `git add -p`로 `_registration_metadata` 3개 hunk와 `validate_proposal` 1개 hunk를 서로 다른 커밋에 배치했다.
- `test_plan_workflow.py`도 `git add -p`로 A′·A-2 hunk를 분리했다.
- `_set_proposal_required_tests`는 A-2 코드와 같은 물리 hunk에 붙어 있었다. `git add -p` 편집기의 `EDITOR`가 설정되지 않아 편집 시도를 폐기한 뒤, 이 함수 추가분만 동일한 cached index hunk로 정확히 stage했다. 작업 파일 내용은 변경하지 않았다.
- 각 commit 전 `git diff --cached --check`와 cached diff를 확인했다.
- 귀속이 불확실해 남긴 hunk는 없다.
