## 작업 요청 — 로컬 CLI 단순화

사용자 결정: "인자 4개 관리는 운영이 어렵다. 간단하게." 안전 의미는 바꾸지 않는

작업 위치: openmetadata-test 작업장 (GitHub), 위 기준 커밋에서 새 브랜치.

### 요구사항

1. om_workflow.py에 간편 서브커맨드 추가 (기존 plan-preflight/plan-validate는
   그대로 두고 내부 호출):
   - `plan start <요청.yaml>` — run-dir 자동 생성(evidence/om-plan-<mode>-<UTC타임스탬프>,
     새 run 규칙과 일치), state-root 기본값(저장소 내 고정 경로), session-id 자동 생성.
     완료 시 run 폴더 경로와 다음 명령을 출력.
   - `plan check [run-dir]` — 인자 생략 시 최신 미완료 run을 마커/state에서 찾아
     plan-validate 실행. 모호하면(미완료 run 2개 이상) 자동 선택하지 말고 목록 출력 후 중단.
2. 모든 기본값은 명시 옵션으로 override 가능해야 한다.
3. 안전 의미 불변: 마커 생성·정리 규칙, run 불변 규칙, 재실행 표, fail-closed —
   래퍼가 이를 우회하거나 약화하면 안 된다. 특히 session-id 자동 생성이
   병행 세션 구분을 깨지 않아야 한다.
4. 반례 테스트 추가: ① start가 기존 run을 재사용하지 않음 ② check가 모호한 상황에서
   중단 ③ 자동 session-id 충돌 없음 ④ 기존 명시 인자 경로와 결과 동일(parity).
5. 기존 테스트 전부 통과 유지. 문서·핸드오프 md는 이 브랜치에 넣지 말 것.
