# /om-implement — 상태: 인터페이스 후보 (미설계)

- 역할 후보: 사람이 승인한 계획(plan_digest)만 코드에 반영. LLM은 계획을 스스로 승인하지 못함.
- 확정 시점: `/om-plan` 실제 출력 형식이 예행연습으로 검증된 뒤 (00 로드맵).
- 지금까지 정해진 경계:
  - 입력은 확정된 `/om-plan` 산출물 + 별도의 사람 검토 기록만 사용 (01A)
  - 이름은 `apply`가 아닌 `implement` — 기존 등록 승인 반영 명령과 혼동 방지 (01 §3.2)
  - 구현은 검사기가 만든 격리 candidate worktree에서만 (04 문서, source-preparation 5항)
- 설계 시작 시 이 폴더에 문제별 기록을 쌓는다.
