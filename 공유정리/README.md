# 공유정리 — OpenMetadata 커스터마이징 자동화 프로세스 (공유·정리용 문서 모음)

이 폴더는 **진행 상황을 다른 사람과 공유하고 정리해 두기 위한 문서 모음**입니다. 내부 작업용 상세 기록(설계·검토·지시 문서)은 상위 `om_plan/` 폴더에 있고, 여기에는 **읽기 쉽게 정리한 요약 문서**만 둡니다.

## 이 프로젝트가 만드는 것 (한 줄)

은행이 OpenMetadata에 넣은 개조(커스터마이징)를 **기능 단위 고유 ID로 등록·관리**하고, 그 ID를 기준으로 **등록·수정·버전업·검증을 자동으로 운영**하는 프로세스. LLM이 제안하고 규칙(검사기)이 검증하며, 사람은 위험·예외·최종 통합만 검토합니다.
