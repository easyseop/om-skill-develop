# skill_develop — 슬래시 명령 설계 히스토리

OpenMetadata 운영 슬래시 명령(`/om-plan`, `/om-implement`, `/om-verify` …)을 만들면서
**세부 문제마다 무엇을 논의했고, 어떻게 해결했고, 무엇을 고려했는지**를 남기는 폴더.

설계 문서(코덱스 산출물)는 "결론"만 담긴다. 여기는 **결론에 이르기까지의 경위**를 담는다 —
나중에 "왜 이렇게 돼 있지?"가 나왔을 때 이 폴더부터 본다.

## 구조

```
skill_develop/
├── om_plan/        ← 1차 구현 대상. 문제별 기록
├── om_implement/   ← 후보 단계. 확정 전 논의만 쌓음
└── om_verify/      ← 후보 단계. 확정 전 논의만 쌓음
```

## 기록 형식 (문제 하나 = 파일 하나)

```markdown
# <문제 이름>

## 문제        ← 무엇이 왜 문제였나
## 논의 경과   ← 나왔던 대안들과 각각의 단점
## 결정        ← 무엇으로 정했고 왜
## 고려한 것   ← 결정하면서 짚은 주의점·한계
## 반영 위치   ← 어느 설계 문서·반례 ID에 들어갔나
## 미결        ← 아직 열려 있는 것
```
